# 安装健微知著 Skill

把下面的话交给支持 Agent Skills 的助手：

> 请从 https://zhangminton731-a11y.github.io/ai-health-intel/sih-intel.zip 下载健微知著 Skill，先检查文件，再按照你当前客户端的技能安装规则安装。已有同名技能时先比较差异，保留旧版本，不直接覆盖。安装后告知是否需要新开会话。最后读取来源健康，并返回医学科研精选最多 5 条，附来源、日期和原文；不足则如实说明。

手动安装：下载 ZIP，解压得到 sih-intel 文件夹。将包含 SKILL.md 的文件夹放入当前客户端指定的技能目录，刷新或新开会话。不同客户端目录不同，请按各自文档操作；本站不自动写入用户电脑的配置。

## 验证

问：“读取健微知著，给我当前医学科研精选 5 条，附日期、摘要与原文；先说明最近采集时间。”

成功时应看到实际采集时间、有来源和原文的条目；不足 5 条要说明。能读取网页但不支持安装 Skill 的助手，可直接读取 llms.txt 中的 JSON 地址。

## 更新与排查

重新下载，比较 SKILL.md，备份后替换。工具不触发时，检查当前客户端是否支持 Skill、目录是否正确、会话是否已刷新、能否访问本站 health.json。

本站提供随批次更新的当前快照、同批日报与 RSS。没有精确小时查询、历史日报库、增量 changes 接口或自动提醒。
