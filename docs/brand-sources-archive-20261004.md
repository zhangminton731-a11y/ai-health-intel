# 品牌、信源与九月档案验收 · 2026-10-04

## 交付与设计

保留 **S·MED＋奇点医研**。医学十字轮廓表达领域，内部三个相连的节点表达证据汇聚；青绿色延续站点主色。移除品牌底部英文，桌面和手机统一图形与文字层级。GitHub 开源按钮位于桌面主题切换上方，手机“更多”也可访问本仓库。

日报使用月份折叠目录、点阵日期与可点击日历。实心点代表有日报、灰点代表未收录，当前日期加圈。月份数量来自真实目录，不使用虚构期号。四个内容模块和三个“更多”入口保持不变。

## 信源准入

读取原始标题与摘要后，调用既有 `score_item`，沿合格文章追溯官方发布方及 Atom 入口；未改动关键词权重。分数是主题相关性规则分，不是 LLM 评审或临床证据等级。

逐条命中词及 feed 地址见 [机器可读审计](source-admission-2026-10-04.json)。Nature 的两个候选中，一个订阅不可用、另一个本次没有达标样例，未纳入配置。既有源不因一次候选测试被删掉。

审核时发现旧评分以子串匹配：`evaluation` 会命中 `valuation`、`series analysis` 会命中 `series a`。`engine/src/sih_ref/core.py` 改为英文词边界匹配并允许常见复数，增加三项回归测试。准入分数及全部页面产物均在修正后重新计算。

真实整轮采集：**19 / 19 个启用源成功、256 条原始记录、46 条当前可推荐资料**。这是本批结果，不代表未来每批都能成功，也不代表新源每篇文章都达到 70 分。

`scripts/monthly_archive.py` 扫描 54 个 Git 采集快照并合并当前采集，以 URL 去重，优先保留更完整摘要，同时保存原始日期及快照 SHA / 批次来源。

## 代码与加载路径

| 文件 | 修改与作用 |
|---|---|
| `templates/site.html` | 医学 SVG、开源按钮、月历、月份目录、历史文章直达与返回上下文 |
| `scripts/monthly_archive.py` | 原始记录恢复、按月导出、回溯日报与合订本 |
| `scripts/build_site.py` | 导出月目录，复制品牌图形，新增两个期刊元数据 |
| `scripts/quality_gate.py` | 校验月目录统计、原文 URL / 日期、日报无重复且属于对应日期 |
| `engine/src/sih_ref/core.py` | 阻止英文词内误命中，保留原有评分权重 |

九月可读正文文件约 **263 KB（未压缩）**，只有打开九月日报、资料或直达文章时才请求；首页只包含月目录，当前 API / RSS 不附带九月正文。请求和结果在会话内缓存，重复切换不重新下载；失败可重试，完成较晚的请求不会覆盖用户后来打开的页面。长期原始资料保存于 `output/archives/`，不会被原有近 20 天滚动窗口淘汰。

因此能明确验证的是加载范围与重复请求减少，而不是未经测量地宣称所有网络环境都快若干毫秒。

## 复现

```bash
python scripts/monthly_archive.py --month 2026-09
python scripts/build_site.py
python scripts/quality_gate.py
python -m unittest discover -s engine/tests -p 'test_*.py'
python -m unittest discover -s tests -p 'test_*.py'
npm test
```

恢复命令需要完整 Git 历史；正常定时构建直接读取持久档案，无需额外历史扫描。来源持续可用性、翻译准确性仍需日常抽查。
