# 2026-10-04 界面、日报与接入验收

## 本轮实现
- 保留科研、产业、情报、热点、日报、Agent 接入、关于、反馈和政策地图。主导航缩短为两字，使用胶囊筛选、浅色卡片、清晰字号与留白。
- 移除单个信源失败的全站横幅；health.json 与后台诊断保留真实失败信息。真正过期的批次仍有时效提醒。
- 卡片显示实际规则计算的推荐指数，不称 AI 评分。热点前三条重点展示、其余列表展示，均含原文摘要摘录和来源日期。没有伪造参与人数、增长率、趋势图或全网讨论热度。
- 长摘要提取完整的方法、结果与限制句；保留原始摘要证据。修正 Oura 等可由原文确认的机器翻译错误。
- 新增 publication 出刊快照，默认展示当前北京日期，最多选近三日 5 篇；每篇保留原文日期。旧 edition_date、editions、text 等按原文日期的接口保持兼容。
- 把已成功采集的 16 篇 Nature 公开摘要持久保存到 output/.state/article_metadata；本次为从实际本地采集缓存迁移，不是生成或编造摘要。后续采集自动复用并保存成功结果；HTML 不可用时尝试 Europe PMC 精确 DOI 摘要，匹配失败仍不发布无摘要内容。
- MCP 遇到临时连接故障或 500/502/503/504 时重试一次；404 等不重试。公网测试脚本支持多轮真实下载、结构校验及 MCP stdio 调用。

## 边界
- 推荐指数是现有相关性规则；真实模型评分、生成式事件综述和跨来源讨论热度尚未启用，需要另行确定模型服务与数据来源。
- 计划每天 7 次采集，GitHub Actions 调度可能延迟；来源当天没有原文时不会制造当天首发。
- 摘要持久快照解决已采内容因云端网络差异丢失；未来新文章仍依赖来源/文献索引可访问且已收录，不承诺所有来源永不失败。
- 一轮或三轮通过只说明本次测试，不能等同长期可用率 SLA。Skill 触发依赖各客户端安装、权限与模型选择。
