# 信源准入与栏目区分 · 2026-10-04

本轮按“最近连续 10 篇中至少 3 篇阅读价值达到 70 分”扩源。**新增 5 个公开摘要索引频道及 FDA 官方公告，启用信源由 19 增至 25。** 两个当前推荐板块改为单一主板块，不再把同一论文和同一推荐理由同时投放给研究者与产业读者。

## 纳入与排除标准

1. **先定来源范围，再取样。** 对一个明确订阅源/索引频道，取截至 2026-10-04、近 90 天内按原文日期排序的最近连续 10 篇；同一天保留上游顺序，重复 DOI/URL 只算一次。不跳过低分、勘误或材料不足的文章去补高分。
2. **使用生产评分。** 智谱 GLM-5.3-flash 对同一材料独立评估两次；五维权重保持不变，代码验算，平均向下取整，封顶 98。评分仍判断读者值不值得读，没有恢复关键词加分。
3. **确认达标才计数。** 两次评分有效、无重大分歧、读者归属一致且总分 ≥70，才算一个达标样本。分歧、模型失败、材料不足不算零分，也不算达标。只要固定的十篇中已有三个确认达标，即满足 3/10；未完成项另外披露。
4. **不足不纳入。** 只有九篇、日期缺失/异常、抓不到材料，或确认达标不足三篇且还有待判项，状态为“待补证”；十篇全部有效评完但不足三篇，则本轮排除。
5. **来源准入不等于文章入选。** 来源审核一律按 ≥70 判断；生产文章仍分别执行 T1 70、T1_5 72、T2 76 的既有门槛。专业媒体不会因为来源通过而自动降到 70 分上首页。
6. **准入窗口与展示窗口分开。** 来源样本可以回看 90 天，当前推荐只保留 Day 0–10；旧样本不能补充当前榜单。一次 3/10 证明这次样本达标，不证明长期稳定性或客观信用等级。

完整记录：[逐篇评分及采集回执](source-admission-2026-10-04-editorial.json)。29 个候选频道做过可接入性探测，其中 16 个有文章进入模型审核，共 156 个样本槽位、130 个有效无分歧的评分结果；失败和分歧均单列。其余候选只有连接探测，明确标为 `not_evaluated`，不能宣传成完成评分。

## 为什么两个板块之前相同

原提示词允许 `audiences=["research","industry"]`，前端按两个标签各展示一次，`build_data` 再把同一条 `reason` 复制给两个板块。常规临床论文只因“可能有转化价值”也会进入产业页。

现在按核心事件判断：

| 板块 | 核心事实 | 不应混入 |
|---|---|---|
| 临床科研 | 研究结果、证据、设计、分析验证、可复用方法、研究规范 | 仅报道融资金额或产品上市的新闻 |
| 健康产业 | 产品上市、审批准入、医保支付、采购落地、融资并购、商业合作、经营与产业政策 | 只有潜在商业前景、没有产业动作的论文 |

一篇文章只能有一个主板块。两次模型归属不同，进入待复核，不能同时填两个列表。页面分别说明“读证据、学方法”和“看产品、看市场”，卡片区分“研究价值/产业价值”；产业卡片/API 去掉研究环节标签。发布质量门检查页面栏目与两个评分回执一致，当前两板块交集必须为空。历史档案保留原有归档身份，不冒称已全部重评。

## 代码与复核方式

- `engine/src/sih_ref/editorial.py`、`prompts/reading_value.md`：单一主板块、分歧暂缓、原始证据与五维评分校验。
- `engine/src/sih_ref/sources.py`：新增 Europe PMC 摘要频道；修复嵌套 RSS 标题、月名日期；保留原始出版时间。
- `dive_metadata.py`：读取出版商公开的 Dive Brief，避免只看一行 RSS 导语；失败时保留原导语，不编写摘要。
- `official_metadata.py`：FDA 公告的原文摘录；保留 `source_excerpt` 标记，抓取失败保留原导语，不凭空补正文。
- `scripts/audit_sources.py`：固定最近十篇，再执行生产评分；`admitted/excluded/pending/not_evaluated` 不混淆。
- `scripts/build_site.py`、`templates/site.html`、`quality_gate.py`：分别投放和展示主板块，阻止双归属回归。

重跑需配置既有 `SIH_LLM_*` 环境变量。冻结采集快照为 `source/status/items/checks/source_tier` JSON 后：

```bash
python scripts/audit_sources.py --snapshots path/to/snapshots --as-of 2026-10-04 --output admission.json
```

同输入复用已校验双评缓存。内容或策略变化才重新评分；没有为跨过门槛而反复重抽已经有效评完的低分样本。网络/输出校验失败可以重试，旧有效回执保留。

本次还发现 FDA 样本的逐字摘录因直/弯引号差异被误拒：现在只允许用一对一引号映射定位，保存时恢复原文片段。任何文字改写、拼接或编造仍然拒绝，权重和门槛未改变。
