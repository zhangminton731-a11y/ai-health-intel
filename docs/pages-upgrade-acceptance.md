## 根因与改动

- 最新线上采集原本已到 10-04 07:47，日报期号是 10-02。10-03 四条 Nature 论文已在事实池，但摘要为空，旧科技/消费健康词表将其归档。
- `article_metadata.py` 只从配置启用的 Nature 原文读取 `dc.description`，保留 `summary_source`，缓存成功摘要，每源每批最多 8 次新请求；不可用时不编写摘要、不绕过访问控制。
- `core.py` 增加医学场景与研究技术交集，保留原产业规则、日期门和原文日期。缺摘要标待查，排除原因保留在事实池。规则候选不是人工精选，也不是临床证据等级。
- `pipeline.py` 最多四个独立来源并发，状态与结果仍按配置顺序写入；基准夹具验证事实输出相同。
- `rss_fetch.py` 在 PR #9 的统一重试预算上增加 ETag/Last-Modified 条件请求。缓存损坏或重定向不能误用 304；失败不覆盖已验证缓存。304 内容仍按本批日期重新评分。
- `publication.py` 提供共同当前集合与按原文日期统计的收录、入选和排除原因；health API 展示覆盖信息。日报显示最近采集时间与最新有内容期号。
- `build_site.py` 不再将隐藏归档条目的摘要/推荐理由重复发给浏览器，完整事实仍在 JSONL；保留历史阅读。`site_assets.py` 生成内容哈希 JS/CSS，主题首帧脚本保留内联。
- `site.html` 只渲染当前路由，搜索文本一次构建；原模块、入口、政策地图、历史阅读、分享与 Agent 接入保留。

## 性能对照

相同保存批次、相同历史列表、关闭新翻译网络请求，只比较渲染产物：

- 原 HTML：617,705 字节。
- 新 HTML：438,956 字节，减少 28.9%。
- 新外部 CSS + JS：49,164 字节；HTML 加代码首次总量为 488,120 字节，较原 HTML 减少约 21.0%。不含未变图片、压缩或 HTTP 头。
- 两份对照的 24 条当前内容、日报目录和 54 条历史阅读 ID 完全相同；不是通过删除可见内容压缩体积。
- 字节数不是浏览器首屏耗时；当前没有 Lighthouse、真实移动网络或线上 P95 对照，不声称首屏快了 28.9%。

`python scripts/benchmark_pipeline.py`：8 个合成来源，每源固定 50 ms I/O，每种配置 5 次；所有事实 JSONL 完全相同。串行中位数 442.26 ms，四路 141.08 ms，减少 68.1%。这是合成调度对照，不是生产采集 SLA。

真实冷启动补摘要会增加请求；本机 HN 本次逐条读取耗时约 67 秒，是尚存瓶颈。未声称本轮所有阶段都更快。内容收益与性能收益分别验收。
