# 阅读价值评分实施与验收

目标：生产筛选由关键词累加改为正文/摘要的模型编辑判断；98 为硬上限；压缩 Logo 区域。

设计：现有采集、去重、时效门保留。生产 profile 开启 editorial 模式，关键词不参与评分或入选；同一模型两次独立请求返回五维整数、受众、中文推荐理由和材料摘录。代码按医学场景权重计算、取平均向下取整，并执行来源门槛。成功结果按正文、模型、提示词与策略哈希缓存。未配置、失败、材料不足均不回退关键词评分。

1. 新增 engine/src/sih_ref/editorial.py 与 prompts/reading_value.md：严格校验、两次请求、缓存、状态；tests/test_editorial.py 验证关键词堆叠无加分、失败关闭、分项/总分校验、缓存失效。
2. core.py / pipeline.py / config / aggregate.yml 接入生产路径。保留 engine 示例旧规则以兼容独立教学示例，不用于生产。
3. build_site.py、历史投影、API、quality_gate.py：只呈现已验证新评分；既有历史资料保留日期和内容，不把旧规则分当新评分；待评内容不入精选、热点、日报。
4. templates/site.html：缩小品牌容器，待评状态、分项说明、真实推荐理由。验收桌面/手机尺寸与无横向溢出。
5. 全量本地测试与发布检查；有配置才运行真实模型验收。无配置时明确报告未完成真实模型测试，不制造结果。

参考：AIHOT selection-score.md、editorial/analyze.ts。医学论文权重提高证据支持，不照搬面向泛 AI 读者的论文权重。未评估全文时如实标注摘要范围。
