      手动安装与更新
      下载 Skill ZIP，解压后把包含 SKILL.md 的 sih-intel 文件夹放入客户端指定的技能目录。更新前比较差异并备份已有版本。
      查看完整安装说明 ↗
      支持的内容与时间范围
      当前快照、同批日报、两个板块及研究环节筛选。时间精度为日期；日报按近 10 天原文日期归集；没有更早的历史存档、精确过去 24 小时查询或增量 changes 接口。
      没有触发？按这个顺序检查
      确认客户端支持 Skill → 确认技能目录 → 刷新或新开会话 → 检查能否读取来源状态。手机是否能安装取决于所用客户端。
      

      用 MCP 调用三个只读工具
      下载本地包，用 Python 3.10+ 创建虚拟环境并安装依赖，再把服务添加到支持 stdio MCP 的 Agent。它在你的电脑上运行，读取本站公开数据。

      使用前了解这几件事
      重要内容回原文核对
      保留来源、日期和原文链接，区分期刊、企业发布和媒体报道。原文的使用权利以发布方要求为准。
      检查实际更新时间
      先读 health.json。超过 36 小时应明确提示数据延迟；没有匹配内容时不要补造条目。
      按需读取
      建议缓存数据，RSS 每 30 分钟或更慢刷新即可；数据按采集批次更新，频繁请求不会产生新内容。
      无需提供个人资料
      这些入口不需要账号、API Key 或访客标识。MCP 的关键词在本地筛选，公开站点只接收数据读取请求。
